# Mitmachen – eine Folge bauen und einreichen

So kommt eine neue HAGNE-Folge vom Einfall ins Repo. Dauert beim ersten Mal etwa eine halbe Stunde, danach deutlich weniger.

## Einmalig einrichten

1. **Claude:** Code-Ausführung einschalten (Einstellungen → Fähigkeiten) und den Skill hochladen: `skill/hagne-studio` als ZIP packen bzw. die ZIP von Julian nehmen, dann **Customize → Skills → hochladen**.
2. **GitHub:** ein kostenloses Konto anlegen und Julian den Namen schicken. Ohne Konto geht es auch: dann die Dateien am Ende einfach an Julian schicken.

## Eine Folge bauen

1. Neuen Chat in Claude starten und die Idee in ein paar Sätzen beschreiben, zum Beispiel:
   > „HAGNE-Folge: m0og will das WLAN-Passwort nicht rausrücken, KickASS rennt dreimal durchs Bild und fragt danach. Vor der Halle, etwa 30 Sekunden.“
2. Claude holt sich den aktuellen Stand aus dem Repo, zeigt erst ein kurzes Szenenbuch in Worten und baut nach deinem OK das Drehbuch. Fehlt eine Geste oder Figur, sagt Claude Bescheid und baut sie mit dir.
3. Du bekommst eine Player-Datei zum Anschauen und einen Kontaktbogen. Änderungswünsche einfach in den Chat schreiben.
4. Wenn alles passt: Claude bitten, **„die Dateien fürs Repo als ZIP“** zu geben. Die ZIP enthält die Ordner genau so, wie sie im Repo liegen.

Eigener Ton (Sprachaufnahmen, Geräusche) ist willkommen: einfach im Chat hochladen. Ohne Ton bewegen sich die Münder gleichmäßig, mit Ton passend zur Stimme.

## Einreichen (Pull Request)

1. ZIP entpacken.
2. Auf https://github.com/cyphrrr/hagne-studio auf **Add file → Upload files** gehen.
3. Den **Inhalt** des entpackten Ordners (also `drehbuecher/`, ggf. `bibliothek/`, `docs/`, `ton/`) ins Fenster ziehen. GitHub behält die Ordner bei.
4. Unten **„Create a new branch for this commit and start a pull request“** wählen, kurz beschreiben, was neu ist, **Propose changes** klicken.
5. Julian schaut drüber und übernimmt. Danach ist die Folge auf der Player-Seite für alle sichtbar.

## Regeln

- Nur Spitznamen, Shirt-Aufdruck immer `['ju:nien]`.
- Nur eigenes Material der ['ju:nien], keine fremde Musik oder Filmausschnitte.
- Keine Rohvideos und keine Fotos echter Personen ins Repo – das Repo ist öffentlich.
