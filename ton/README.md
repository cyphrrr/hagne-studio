# Tonspuren

Hier liegen die fertig gemischten Tonspuren der Folgen, mit demselben Namen wie `ton.mix` im Drehbuch (z. B. `e02.mp3`, `guertel.mp3`). Der Player auf GitHub Pages lädt sie von hier.

Nur eigenes Material der ['ju:nien] und nur fertige Mischungen – keine Rohaufnahmen. Entschieden im Nov. 2026: Die fertigen Tonspuren dürfen öffentlich hier liegen. Ohne Datei läuft der Player stumm mit einer Uhr, über „Ton laden“ lässt sich eine lokale Datei wählen.
