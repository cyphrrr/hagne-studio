# Tonspuren

Hier liegen die fertig gemischten Tonspuren der Folgen, mit demselben Namen wie `ton.mix` im Drehbuch (z. B. `e02.mp3`, `guertel.mp3`). Der Player auf GitHub Pages lädt sie von hier.

Nur eigenes Material der ['ju:nien] und nur fertige Mischungen – keine Rohaufnahmen. Ob die Tonspuren öffentlich hier liegen sollen, entscheidet das Media-Team. Ohne Datei läuft der Player stumm mit einer Uhr, über „Ton laden“ lässt sich eine lokale Datei wählen.
